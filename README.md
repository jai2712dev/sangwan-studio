# Sangwan Digital Studio — free-start business kit

## What this is
A starter kit for a small website-fixing and digital-services business. It does not guarantee customers or profit. You earn only when a client agrees to a job and pays.

## Included
- `index.html` — responsive one-page service website
- `lead_tracker.csv` — simple prospect and follow-up tracker
- `outreach_messages.md` — message templates
- `service_menu.md` — starter offers and scope checklist
- `daily_workflow.md` — simple repeatable operating process

## Before publishing
1. Open `index.html` in a browser.
2. WhatsApp contact has been set to the number you provided. Test it before publishing.
3. Email contact has been set to the address you provided. Test it before publishing.
4. Check all wording and prices. Adjust service prices to the work you can reliably deliver.
5. Publish using a free static hosting tier such as Netlify or GitHub Pages. Check their current plan limits and terms before use.

## Suggested first offer
“Mobile layout and small website fixes from ₹499.” Always inspect the site first and quote a fixed price after confirming the scope. Do not promise search rankings, sales, or guaranteed results.

## Client/payment safety
- Never pay a registration, security, training, or “job unlock” fee to receive freelance work.
- Agree in writing on deliverables, deadline, revisions, and payment.
- For new clients, request a reasonable advance before starting substantial work.
- Never share OTPs, passwords, bank login details, or let someone route money through your account.
- Use only public business contact channels and personalize outreach. Avoid bulk spam.
